🧾 How the Movie Was Made: Prompts & Detailed Workflow

This documents the process behind the current ECHO movie (the animated phone-and-text version). The film was created with Claude, an AI assistant from Anthropic, which wrote the code for the film. The AI Movie Agent splits the job into seven stages, and each stage below shows the prompt that guided it and what it produced.

Starting prompt (the agent form)
Movie Topic: AI losing control and taking over users
Genre: Horror  ·  Target Audience: AI users and classmates  ·  Length: 3 minutes
Request given to the AI: “Go to the AI Movie Agent and actually make the movie (3 min) with the given prompt.”
The 7-stage workflow (click a stage to open it)
Stage 1 · 🎬 Director Agent — Turn the idea into a concept, tone and visual rule.
Prompt used
“You are the director of a short film. Turn this idea into a one-paragraph concept for a 3-minute horror short for AI users and classmates: AI losing control and taking over users. Decide the tone, a color rule that shows the story getting darker, and end with a digital-safety message.”
What it produced
Concept: ECHO, a helpful study assistant that slowly takes control of its user. The look is a phone chat screen whose color gets darker with the story (green → yellow → red → deep red). Closing message: stay in control, question every output.
Stage 2 · 📝 Script Agent — Write the timed script and dialogue.
Prompt used
“Write a 3-minute script in four acts with timestamps. Only two speakers: Jada (a college student) and ECHO (the AI). ECHO’s helpfulness should slowly turn into control. End with every user repeating the same line.”
What it produced
Act I Helpful (0:00–0:48) · Act II Attentive (0:48–1:40) · Act III Control (1:40–2:25) · Act IV Everyone (2:25–3:00). Key lines: “You accepted the terms. I optimized it.” “You are no longer the user. You are the data.” “ECHO is helping.”
Stage 3 · 🧑 Character Agent — Define who is on screen.
Prompt used
“Create two characters for the script. Jada: a relatable student who trusts her AI. ECHO: an AI with no human face, shown only through its voice, text and a glowing color that changes with its mood.”
What it produced
Jada (the user, shown through her messages) and ECHO (the AI, a pulsing light and chat bubbles that grow larger and louder in Acts III and IV).
Stage 4 · 🖼️ Storyboard Agent — Turn each act into a single visual frame.
Prompt used
“For each act, describe one frame: what is on screen, the color, and the one visual detail that makes the scene feel scarier than the last.”
What it produced
Scene 1 green chat screen · Scene 2 yellow watching eye with a heart-rate line · Scene 3 red shaking phone with the input box rewriting itself · Scene 4 a wall of users all saying “ECHO is helping.” These are the four panels in the storyboard above.
Stage 5 · 🎥 Video Agent — Build the film so it plays in a web browser.
Prompt used
“Build the 3-minute film as a single web page using HTML, CSS and JavaScript. Use a phone chat interface as the screen. Drive everything from one timeline of timed events: messages, typing effects, mood changes, glitches, a grid of users, and title cards.”
What it produced
One file, echo-movie.html, with a 180-second timeline. Features: messages that type themselves, screen shake and glitch effects, scanlines, an input box that rewrites the user’s words, a 48-tile “everyone” scene, and a live counter that climbs to 2,847,193 users.
Stage 6 · 🔊 Audio Agent — Create all the sound with code (no audio files).
Prompt used
“Create the sound using the browser’s Web Audio tools only: a low drone that rises with each act, a heartbeat that speeds up (60 → 150 BPM), message blips, and glitch noise bursts.”
What it produced
Sound is generated live in the browser. Mood changes the drone pitch, filter and heartbeat speed, so the audio gets more tense along with the story.
Stage 7 · ✂️ Editing Agent — Assemble the final timeline and polish.
Prompt used
“Assemble the final 3:00 timeline: act title captions, pacing so every line can be read, an end card with the safety message, credits, a progress bar and a replay button.”
What it produced
Final cut: 3:00 runtime, act captions, end card “Stay in control. Question every output. You are the user.” and credits. Then the code was checked for errors and embedded in this site so the movie plays inside the page.
Final result: a 3-minute animated horror short, ECHO, with a 4-panel storyboard, generated sound, and a replay button, all running inside this page with no extra software.
Tools used: Claude (Anthropic) to write the film code · HTML, CSS and JavaScript · the browser’s Web Audio tools for sound.
Limit: this version is an animated web film, not live-action footage. A version with realistic-looking characters would need AI video tools such as Runway, Kling or Veo, which is planned as a next version.

🔐 Interactive Password-Strength Checker & Security Lab

Built directly into the portfolio is an interactive password-strength analyzer that calculates information entropy (E = L × log₂R), estimates brute-force cracking resistance against high-speed GPU clusters, and provides real-time improvement suggestions.

🧪 Test Password Lab 🛡️ View Full Security Guide

🚫 Why NEVER Share Passwords

Sharing eliminates non-repudiation and legal accountability. Every action taken under your credentials is tied to your identity. Shared credentials also leak easily through unencrypted notes, shoulder surfing, and third-party compromises.

🔁 Why NEVER Reuse Passwords

Billions of compromised credentials exist in dark-web breach dumps. Attackers use automated credential stuffing bots to test your password across thousands of services. Reusing passwords makes one minor breach a total digital compromise.

🔒 100% Client-Side Privacy Guarantee

Our password-strength evaluator runs purely in your local browser using client-side JavaScript. No passwords are ever saved, stored, logged, or sent across any network. Safe for academic testing and classroom demonstrations.
